# Toggle_Sketches

An add-in for Autodesk Fusion that pins a button to the quick-access toolbar, allowing the user to toggle sketch visibility, and eliminating the need to scroll through the browser to find the sketch folder (which can be time consuming in larger designs). The tool toggles visibility of the parent sketch folder in the active component, and does not affect the visibility of individual sketches. Sketch folders in inactive components are also unaffected.
