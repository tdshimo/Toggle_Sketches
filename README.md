# Toggle_Sketches

This add-in for Autodesk Fusion pins a button to the quick-access toolbar that allows the user to toggle sketch visibility, eliminating the need to scroll through the browser to find the sketch folder (which can be time consuming in larger designs). The tool toggles visibility of the parent sketch folder in the active component, and does not affect the visibility of individual sketches. Sketch folders in inactive components are also unaffected.
